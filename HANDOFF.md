## Current mathematical model

The full RGB field is piecewise across a fixed 4x4 spatial partition. Each region
has a SIREN-style coordinate network:

```text
local (x,y,t), normalized to [-1,1]
 -> affine 3→64 -> sin(30·z)
 -> affine 64→64 -> sin(30·z)   (three such hidden transitions)
 -> affine 64→3
 -> RGB = clamp((output+1)·127.5, 0, 255)
```

There are four hidden sine layers total, five affine layers, 206,896 parameters
across the 16 regions. Playback has no frame lookup. All frames/time samples are
generated by evaluating the functions. Quantization uses signed integer
coefficients in [-2047,2047] and a floating per-layer scale. Exported `.rs` stores
plain numeric arrays, not base64 or compressed assets. Coefficients are dequantized
once at startup. Dot products use independent accumulation lanes; rows are
evaluated using scoped std threads (up to eight by default in the player).
